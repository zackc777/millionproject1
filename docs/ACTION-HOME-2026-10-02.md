# 以待辦與動作為入口

基底 main 207fc12；僅 zackc777/millionproject1。

首頁改為每日可花、優先待辦、常用操作及逐卡帳單入口。待辦按逾期、近七日到期、缺資料、預算缺口、其餘卡費／收入／投資計畫排序，預設最多四項，其餘收折。投資計畫提醒不代表已成交，未推測未完成金額。

新增可搜尋的操作面板（Ctrl/Command K），包含現金對帳、薪資、消費、投資、存款、逐卡帳單與繳款，及研究、學習、決策等入口。直接操作沿用既有 CRUD 表單，沒有自動寫入財務資料。快搜採動作與關鍵字比對，未串接語言模型，不假裝自然語言推理。

每月薪資、預算、明細新增精確定位，開啟時自動展開及聚焦。總覽保留目標、預備金、任務、研究與完整資產計算入口，手機側導覽等既有模組不移除。

帳單快捷與卡片頁同樣依期別月份開啟已存在帳單，避免實際結帳日與設定日不同時重複新增。

只執行必要 production build；依使用者延續的不要測試要求，沒有自動或瀏覽器驗收。沒有資料库變更，也未新增使用者金流。
