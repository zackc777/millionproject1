# 現金對帳與操作回應改善

基底：main 308a75d4d1bb9ddc546398ab5e2dd36e4bc8ad89；唯一 repository zackc777/millionproject1。

## 本次範圍

- 新增日終現金對帳：銀行合計、手上現金、其中的預備金及專用存款。支援新增、編輯、刪除，revision 防止跨裝置覆蓋。
- 對帳為絕對餘額基準；之前漏記的金流補登後，不再從已確認餘額扣除。對帳差額獨立列示，不推測收入或消費類別，不變更信用卡欠款。
- 以最新不晚於查詢日期的對帳為準，其後金流繼續累加；刪除後恢復以前的基準。其他後續對帳仍有效。
- 預備金與專用存款包含在银行／現金總額，不重複加總。投資市值、卡片額度不填入銀行餘額。
- 因既有金流只有日期，日終对帳最晚為昨天；不允許今天，以免同日稍後交易被基準吃掉。
- 尚無對帳、超過 31 天或存款分配出現負數時，顯示待核對並暫停追加配置；對帳後仍明示為依已記錄金流推估，無法知道漏記的分類。
- 歷史月份資產區現金會重算；投資市值保留當月快照。年度快照表仍表示原保存數值，不是重算歷史。
- 導覽保留最後點選目的頁，避免載入中忽略後續點擊；狀態提示即時呈現。快速投資入口等待目標頁完成後開啟，不使用固定延遲。
- 預算在 render 前載入，取消預算載入後的整頁重畫及輪詢；獨立頁面資料與後處理並行讀取，不新增長期金流快取。
