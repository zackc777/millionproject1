基底：`zackc777/millionproject1` main `be5d4baf7017d9dbc82fa0d217e7573cfc6131c0`。

## 原因與資料契約

首頁原本直接強調淨資產，容易被理解為沒有把投資與預備金列入資產。唯讀核對顯示，現金、專用存款、預備金與投資已納入；扣除未繳帳單後才出現負數。本次不調整任何使用者紀錄，也不自動標記帳單已繳。

- 新增共用 `assetSummary`，明確區分 `grossAssets`、`cardDebt`、`netAssets`。
- `totalAssets` 保持淨資產語意，歷史快照契約不變；百萬目標保持扣債後進度，負值顯示 0% 並解釋原因。
- 現金對帳的銀行合計包含預備金與專用存款，不能再加一次；補充勿先扣待繳卡費的提示。
- 修正信用卡頁未傳入 `cash_reconciliations` 的缺漏，與首頁及每月財務使用相同現金基準及配置模型。載入預備金目標後再計算。

## 介面

首頁保留百萬目標進度、總資產減負債的可見算式、資產圓環、預備金進度、日常摘要、逐筆待繳帳單與下一步。移除與月度頁重複的支出、金流、預算和配置區塊。

每月財務保留可見的收支圖塊、每日可花、金流長條、消費圓環、生活預算比較與追加配置；移除重複資產圓環、預備金卡與支出文字回顧。對帳與快照保留入口及歷史資料，簡化重複資產卡。

信用卡頂部只呈現待繳、消費及已繳三種數字，不再顯示未載入投資資料的淨資產。保留帳單、卡片設定與繳款 CRUD。設定、對帳、收支 CRUD 和預備金目標修改入口均保留；桌機 sidebar 與手機底部導航不變。

限制首頁 grid 最小寬度，數字和帳單按鈕於窄螢幕換行。圖表沿用 SVG/CSS，沒有新增依賴、輪詢、View Transition 或 chart fetch。
