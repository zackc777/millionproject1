# 財務中心整理與跨月配置

基底 main 11ce407，僅限 zackc777/millionproject1。

問題：帳單存在性使用結帳日期精確相等，設定日與銀行實際結帳日不同時誤判缺件；配置基礎取本月資金增減與累積現金的較小值，導致結轉現金未正常參與。卡費消費與付款兩種統計、資金增減與現金餘額也重複分散呈現。

變更：
- 帳單月按卡片及應有期別月份核對，保留銀行實際日期；不改寫卡片設定或帳單資料。
- 配置採未指定用途現金（含結轉），再扣卡費、必要生活／未出帳預留。每日分母包含今天。
- 資料缺件列出具體原因及入口。尚未確認現金時只顯示「每日預算參考」，不稱為可花金額；追加投資仍保守暫停。
- 總覽與每月財務使用相同建議元件。歷史月顯示回顧提示及本月入口。
- 每月財務聚焦現金、淨資產、認列消費、實際扣款及每日上限。薪資、預算、配置、分析、資產、歷月改為收折；移除重複摘要，新增卡片帳單／付款對照。
- 同月更新保留收折及捲動位置，快速切月只允許最新讀取結果畫面落地。

沒有修改使用者金流、帳單或資料庫結構。依使用者延續的指示，未跑測試或桌機／手機驗收，只執行 production build。部署狀態不能視為實際操作驗收。
